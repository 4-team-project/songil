# 🧾 Takku (딱쿠) 프로젝트 - 펀딩 기반 소상공인 쿠폰 플랫폼

> **“누구나 쉽게 펀딩 만들고, AI가 대신 홍보해드립니다.”**  
> 소상공인은 상품만 올리고, AI가 알아서 홍보하고 팔아주는  
> 진입장벽 없는 펀딩 쿠폰 플랫폼

---

## 🧑‍💻 프로젝트 소개

**Takku(딱쿠)**는 오프라인 소상공인을 위한  
**AI 자동 홍보 + 펀딩형 쿠폰 판매 플랫폼**입니다.

- 상품을 등록하면, **AI가 자동으로 홍보문구를 생성**하고,
- 소비자는 **펀딩 방식으로 쿠폰을 사전 구매**할 수 있으며,
- **정산은 빠르게**, 사용은 **기프티콘처럼 간편하게**!

**IT에 익숙하지 않은 사용자도 쉽게 사용 가능하도록**  
Easy Mode UI/UX를 통해 진입장벽을 최소화했습니다.

---

## 🎯 프로젝트 주요 목표

- ✅ 소상공인의 안정적인 매출 확보
- ✅ AI 자동 마케팅 기능 제공
- ✅ 누구나 쉽게 사용할 수 있는 UI/UX
- ✅ 소비자에게는 희소성 기반 쿠폰 제공

---

## 🔍 주요 기능 요약

### 1. 펀딩 기반 쿠폰 발행
- 소상공인이 직접 상품/쿠폰을 등록
- 펀딩 성공 시 수익 정산 → 빠른 자금 확보
- QR 기반 사용으로 간편한 소비자 경험

### 2. AI 기반 홍보 자동화
- 입력된 정보를 바탕으로 마케팅 문구 자동 생성
- 해시태그, SNS 문구, 타겟 맞춤 문구 제공
- **할인보다 희소성과 스토리 강조**로 마케팅

### 3. Easy / Pro UI 모드
- **Easy Mode:** 쉬운 단어, 큰 버튼, 단계별 안내
- **Pro Mode:** 고급 기능, 상세 통계, 성과 분석

### 4. 판매/매출 데이터 분석
- 펀딩 성공률, 판매 추이, 피드백 통계 제공
- 지역/계절 기반 추천 상품 제안 기능 예정

### 5. 소비자 혜택
- 저렴한 사전 구매 쿠폰
- 리뷰 기반 스마트 소비
- 다양한 로컬 소상공인 상품 탐색
